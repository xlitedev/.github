# XLITE

**[XLITE](https://xlite.dev)** is a small development team in Moldova building web, mobile and AI products for clients worldwide, mostly with Laravel, [Filament](https://filamentphp.com) and TypeScript.

## Products

- **[Packstub](https://github.com/packstub)**: open-source Filament plugins and the Laravel packages behind them, plus Pro plugins when you need more. [packstub.dev](https://packstub.dev)
- **[reelson](https://github.com/reelson/reelson)**: a prompt in, a branded demo video of your web app out, through Agent Skills and a CLI for coding agents.
- **[Orderflux](https://orderflux.io)**: order management for shops selling in several countries, with local couriers, cash on delivery and invoicing per company.

## Open source here

- **[Claude Telegram Switch](https://github.com/xlitedev/claude-telegram-switch)**: a multi-bot Telegram channel for Claude Code, so you can chat with any running session from your phone.
- **[Lamx](https://github.com/xlitedev/lamx)**: Laravel apps with htmx, server-rendered and fast.
- **[Linters config](https://github.com/xlitedev/linters-config)**: the ESLint, Prettier and Stylelint setup our projects share.
